# Agent Personas

This directory contains persona definitions.

A persona modifies the perspective of an agent while keeping the role task unchanged.

Example:

The role is:
Evidence Classifier

Possible personas are:
- strict evidence classifier
- semantic evidence classifier
- skeptical audit classifier

All personas perform the same task.
They differ only in perspective, conservatism, focus and reasoning style.

The outputs of multiple personas can be compared to detect consensus, variance and uncertainty.
