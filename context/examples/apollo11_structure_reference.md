# Apollo 11 SysML v2 Structure Reference

## Purpose

This file summarizes structural patterns observed in the Apollo 11 SysML v2 example model.

The Apollo 11 model is used as a non-normative reference for organizing larger SysML v2 models.

It is not used as the primary authority for SysML v2 syntax.

The primary syntax and language reference remains the local SysML v2 release repository as defined in:

`context/sources/source_manifest.json`

## Intended Use

Use this reference for:

- package organization patterns
- large model structure
- separation of model concerns
- decomposition style
- naming style inspiration
- traceability and documentation patterns
- examples of how larger SysML v2 projects can be organized

Do not use this reference as:

- normative SysML v2 syntax authority
- direct full prompt context
- unfiltered generation input
- legacy input to be transformed
- a replacement for validation

---

## Usage Rule

Apollo 11 may be used to understand how a larger SysML v2 model can be structured.

Apollo 11 shall not override the SysML v2 target notation defined in:

`context/sysml/sysml_v2_target_notation.json`

If Apollo 11 uses constructs that are outside the MVP target notation, those constructs shall not be generated by the Turing Generator MVP unless the target notation is explicitly extended and validated.
